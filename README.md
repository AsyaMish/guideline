# guideline
Приложение для создания быстрого гайдлайна стилей и параметров проектов 
# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Приложение «Гайдлайны проектов»

## 1. Суть проекта

Веб-приложение для веб-дизайнера, которое позволяет создавать **гайдлайны проектов** (дизайн-документацию): цвета, типографику, кнопки, поля ввода, скругления, тени, отступы и сетку. Один проект = один документ. Заполняется вручную, хранится локально, работает оффлайн, синхронизируется между устройствами вручную через файл. Выгружается в PDF/CSV/JSON.

**Ключевая идея:** значения, которые повторяются (цвета, шрифты, радиусы, тени), вводятся **один раз** в своём разделе, а во всех остальных местах используются **как ссылки** на эти значения. Это исключает рассинхронизацию: поменял цвет в разделе «Цвета» — он обновился везде, где выбран.

**Целевая платформа:** веб-приложение, адаптивное под десктоп и мобилку (мобильная вёрстка — полноценная, не сжатая десктопная). Оффлайн-работа с локальным хранением.

## 2. Общая архитектура и экраны

### 2.1. Главный экран «Мои проекты»

- **Вверху** — заголовок «Мои проекты» (визуальная отбивка от края).
- **Список проектов.** Каждая строка:
  - Название проекта.
  - Краткое описание (пара слов, редактируется).
  - Дата последнего изменения.
  - **Метки версий:** «ПК», «Планшет», «Телефон» — появляются только для тех версий, где что-то заполнено. Пустой проект — без меток.
  - **Иконка-шестерёнка** → выпадающее меню действий:
    - «Дублировать» — полная копия проекта **со всеми значениями**, в названии добавляется «копия».
    - «Удалить» — с подтверждением.
    - «Экспорт» — переход на экран экспорта.
  - Клик/тап по строке — открыть проект.
- **Нижняя фиксированная панель** (не плавает, зафиксирована внизу):
  - Слева — иконка поиска (поиск по названию и описанию).
  - По центру — большая круглая кнопка «+» («Новый проект»).
  - Справа — иконка фильтров.
- **Фильтры** (сквозные, панель сворачиваемая): по дате, по меткам версий, «есть разорванные связи».
- **Пустые состояния:**
  - Нет проектов вообще → «Создайте первый проект» + кнопка.
  - Фильтры ничего не нашли → «Проектов по данным параметрам не найдено».

### 2.2. Создание проекта

- Нажатие «+» → короткая форма: **название** (обязательно), **краткое описание** (необязательно).
- Кнопки «Создать» / «Отмена».
- После «Создать» открывается **содержание** проекта (десктоп-версия, все разделы с пустыми значениями).

### 2.3. Содержание проекта

- **Наверху:** переключатель версий **Десктоп / Планшет / Мобилка** (по умолчанию Десктоп). Название и описание проекта редактируются здесь же.
- **Список разделов** (интерактивный):
  1. Цвета
  2. Типографика
  3. Кнопки
  4. Поля ввода
  5. Скругления
  6. Тени
  7. Отступы и сетка
- **Разделы списка свёрнуты по умолчанию.** Клик по заголовку раздела разворачивает список его пунктов, повторный клик сворачивает. Кнопка-стрелка открывает раздел целиком. При активном поиске или фильтрах разделы с подходящими пунктами раскрываются автоматически.
- **Приложение запоминает последний открытый экран:** после перезапуска открывается то же место (тот же проект/раздел), а все изменения появляются на экране сразу, без ручного обновления.
- **Индикаторы у каждого раздела** (независимые, показывают состояние **текущей версии**):
  - **Зелёная галочка** — в разделе есть хоть какие-то данные.
  - **Перечёркнутая цепочка** (иконка связи, перечёркнутая) — в разделе есть разорванные связи.
- Клик по разделу → переход внутрь.
- **Нижняя панель:** ← (на главный экран) / фильтры / → (**скрыта** в содержании).
- **Содержание одинаковое во всех версиях**, но при переходе в раздел в адаптиве видны только меняющиеся поля.

### 2.4. Экран раздела (внутренний вид)

- **Вверху:** стрелка «Назад» → возврат в содержание; заголовок раздела; **переключатель версий** (кроме разделов «Цвета» и «Тени» — они сквозные).
- **Элементы списка свёрнуты по умолчанию.** Свёрнутая строка: название + краткая сводка (у каждого раздела своя, см. ниже). Пусто — «не задано».
- **Раскрытие по клику** — показывает поля для заполнения.
- **Комментарии** — отдельное поле под элементом/полем там, где предполагается.
- **Кнопка «Добавить»** — внизу списка, после предустановленных элементов. В подгруппах (например, в типографике) — своя кнопка в каждой подгруппе.
- **Автосохранение — постоянно**, независимо от нажатия «Сохранить». Кнопка «Сохранить» есть для привычки (по факту данные уже сохранены).
- **Нижняя панель:** ← (предыдущий раздел, если первый — в содержание) / фильтры / → (следующий раздел).

### 2.5. Экспорт (из проекта, доступен также с главного через шестерёнку)

- **Выбор версий:** все (Десктоп + Планшет + Мобилка) или только нужные (галочками).
- **Выбор объёма:** «Только заполненные» / «Все поля» — **спрашивается каждый раз заново**. Пустые поля в режиме «Все поля» показываются прочерком «—».
- **Форматы:**
  - **PDF:** «Технический» (сухие таблицы значений) и «Для клиента» (обложка с названием/описанием/датой, оглавление, читаемая вёрстка).
  - **CSV:** для Excel (плоская таблица «Раздел | Поле | Версия | Значение»), поддерживает импорт обратно.
  - **JSON:** резервная копия проекта целиком.
- **Предпросмотр** — только просмотр, без редактирования.
- **Кнопки:** «Экспорт» (PDF/CSV), «Резервная копия (JSON)», «Импорт» (CSV/JSON).

### 2.6. Импорт

- **Выбор режима при импорте:**
  - **«Обновить полностью»** — текущие данные стираются, записываются импортируемые. С предупреждением о замене.
  - **«Слить»** — без потери данных:
    - Совпадающие поля → остаётся **более свежее по дате изменения** (у каждого поля — служебная дата).
    - Поля только в импорте → добавляются.
    - Поля только в моей базе → сохраняются.
    - Пустое в импорте → не затирает заполненное моё.
    - Если в импортируемом файле нет даты (например, CSV из Excel) → приоритет **моей базе**.
- Сравнение — по полям **внутри проекта**.

### 2.7. Настройки

- **Тема:** по умолчанию как в системе, с переключением светлая/тёмная.
- **Экспорт всей базы (JSON)** и **Импорт всей базы (JSON)** — с выбором режима (полностью/слить), логика как в п. 2.6.
- **Синхронизация:** только вручную через файл, по необходимости. Никаких аккаунтов, облака, автосинхронизации, индикаторов статуса, уведомлений.
- **О приложении** — версия.

## 3. Разделы документа (детально)

### 3.1. Цвета

- **10 предустановленных полей:** Основной, Акцентный, Дополнительный, Цвет карточек и плашек, Акцент наведение (hover), Ошибка, Успех, Неактивно, Текст тёмный (основной), Текст светлый.
- **Действия:** добавление, удаление (по общим правилам), переименование, перетаскивание (порядок сохраняется и отражается в выпадающих списках везде).
- **HEX-коды вводятся только здесь.**
- **Раскрытый элемент:** название (редактируется), HEX-поле, **кружочек-образец** (заполненный цветом или перечёркнутый, если пусто), комментарий, «Удалить».
- **Свёрнутая строка:** кружочек + название + HEX (или «не задано») + индикатор разорванных связей.
- **Сквозной раздел** — одинаковый во всех версиях, переключатель версий не показывается, в адаптиве доступен как аналог десктопа без переключения.
- Если в разделе «Цвета» чего-то не хватает — из любого поля выбора цвета есть кнопка-переход «Добавить цвет» в этот раздел.

### 3.2. Типографика

- **Три группы:**
  - Заголовки: H1, H2, H3 (предустановлены).
  - Основной текст: T1, T2, T3.
  - Мелкие подписи: MP-1, MP-2, MP-3.
- **Добавление** — «Добавить пункт» в каждой группе (следующее по порядку: H4, T4, MP-4…). **Удаление** — со схлопыванием нумерации без дырок (удалила T3 → T4 становится T3). Переименовывать нельзя (это ID). Порядок внутри группы фиксированный (иерархия).
- **Первичные источники:**
  - «Шрифт заголовки» — подтягивается во все H*.
  - «Шрифт основной текст» — подтягивается во все T* и MP*.
- **Раскрытый элемент:**
  - Комментарий (многострочный).
  - Шрифт (из первичного источника, ручная правка + сброс при изменении первичного).
  - Начертание — фиксированный выпадающий список (Light, Regular, Medium, SemiBold, Bold…).
  - Кегль — px.
  - Цвет текста — выбор из «Цветов» (по умолчанию «Текст тёмный (основной)» у каждого поля своё).
  - Межстрочный — число + переключатель **% ↔ коэффициент** (по умолчанию: заголовки 110%, текст и подписи 140%, для каждого поля отдельно).
  - Межбуквенное — число + переключатель % ↔ коэффициент (по умолчанию 0%).
  - «Удалить».
- **Свёрнутая строка:** название + сводка («Кегль N, Начертание») или «не задано».
- **Адаптив:** показываются только кегль, межстрочный, межбуквенный. Шрифт, начертание, цвет — сквозные, скрыты.

### 3.3. Кнопки

- **Два стиля:** Заливка и Обводка (фиксированные названия).
- **Размеры:** старт с **L**. Две кнопки: **«Добавить большего размера»** / **«Добавить меньшего размера»** (XL, XXL… / M, S…). Удаление со схлопыванием. Названия — ID.
- **Сетка:** стиль × размер (L-заливка, L-обводка и т.д.).
- **Раскрытый элемент:**
  - Комментарий.
  - **Состояния** (вложенный список): обычное, hover, active, disabled, focus (+ можно добавить свои). У каждого состояния **свои цвета**:
    - Фон (для заливки).
    - Текст — ссылка на типографику (цвет подтягивается) + своя ссылка на цвет.
    - Обводка — цвет + толщина (px). Для заливки по умолчанию пусто; для обводки обязательна.
  - **Типографика** — **одна** ссылка на стиль из «Типографики» на всю кнопку (оттуда шрифт/начертание/кегль/цвет), ручная правка + сброс.
  - Скругление — ссылка на «Скругления». У кнопок по умолчанию уже связана с «Скруглением кнопок» (значение пустое).
  - Высота — px.
  - Отступы внутри — верт./гориз., px.
  - Тень — ссылка на «Тени» (по умолчанию связана с «Тенью кнопок», значение пустое).
  - «Удалить».
- **Подстановка:** параметры основной (L-заливка) подтягиваются в остальные (с ручной правкой и сбросом). Для обводки всё подтягивается из заливки, **кроме цвета** — цвета меняются местами (фон заливки → обводка).
- **У заливки есть поле обводки** — по умолчанию пустое, при необходимости добавляется.
- **Адаптив:** меняются высота, отступы, скругление, кегль. Цвета, обводка, состояния — сквозные.

### 3.4. Поля ввода

- **Размеры:** старт с **L**, добавление больше/меньше, удаление со схлопыванием.
- **Раскрытый элемент:**
  - Комментарий.
  - **Состояния** (вложенно): обычное, focus, error, disabled (+ свои). У каждого:
    - Фон.
    - Текст (введённый) — ссылка на типографику + цвет.
    - Плейсхолдер — **своя** ссылка на типографику + цвет.
    - Обводка — цвет + толщина.
  - **Label** — **своя** ссылка на типографику + цвет (одна на поле).
  - Скругление — выбор ссылки из «Скруглений». Если там ещё пусто — показываются предустановленные пункты + кнопка «Добавить новое скругление» с переходом в раздел. Предустановленного «Скругления полей ввода» **нет** — поле пустое.
  - Высота, отступы — px.
  - Тень — ссылка на «Тень полей ввода» (связь по умолчанию, значение пустое).
  - «Удалить».
- **Адаптив:** меняются высота, отступы, скругление, кегль. Label, текст, плейсхолдер, цвета — сквозные, скрыты.

### 3.5. Скругления

- **Предустановленные пункты:** «Скругление кнопок», «Скругление карточек», «Скругление плашек». Названия редактируются, добавление новых, удаление по правилам (предустановленные — только очистка).
- **Раскрытый элемент:** название (редактируется), радиус (px) с переключателем **«общее / по углам»** (по умолчанию общее; при включении четыре поля заполняются текущим значением, правишь нужный угол; при возврате — если все равны, одно число, если разные — первое значение первого угла), комментарий, «Удалить».
- **Свёрнутая строка:** название + значения через дробь (например, «8/4/8/4») или «не задано».
- **Размерной логики (L/больше/меньше) здесь нет** — своя структура через именованные пункты.
- **Адаптив:** переключатель версий есть, меняется только радиус.

### 3.6. Тени

- **Предустановленные пункты:** «Тень кнопок», «Тень карточек», «Тень плашек», «Тень полей ввода». Названия редактируются, добавление, удаление по правилам.
- **Раскрытый элемент:** название, комментарий, **слои** (по умолчанию один), «Добавить слой», «Удалить пункт».
- **Каждый слой:** переключатель **внешняя / внутренняя** (свой у каждого слоя), смещение X (px), смещение Y (px), размытие (px), растяжение (px), цвет (из «Цветов»), прозрачность (%), перетаскивание (порядок), удаление слоя (минимум один; удалить последний = удалить пункт, предустановленный нельзя).
- **Свёрнутая строка:** название + «N слоёв».
- **Сквозной раздел** — в адаптиве не меняется, переключатель версий не показывается.

### 3.7. Отступы и сетка

- **Две вкладки: «Отступы» и «Сетка».**

**Вкладка «Отступы»:**
- Предустановленные пункты: «Между блоками», «От картинки до текста», «От текста до картинки», «От заголовка до подзаголовка», «От подзаголовка до подзаголовка меньшего порядка», «От подзаголовка меньшего порядка до основного текста», «От текста до кнопки», «От кнопки до текста», «От верхней границы блока до контента», «От контента до нижней границы блока», «Между карточками по горизонтали», «Между карточками по вертикали», «От контента до карточки сверху», «От карточки до контента снизу».
- Названия редактируются, добавление/удаление.
- **Раскрытый элемент:** название, значение (px), комментарий, «Удалить». Свёрнутая строка: название + значение (или «не задано»).
- **Адаптив:** меняется значение.

**Вкладка «Сетка»:**
- Поля: ширина контейнера, количество колонок, межколоночный отступ (gutter), боковые поля, макс. ширина контента — пустые по умолчанию.
- Кнопка **«Заполнить 12-колоночной сеткой Tilda»** — подставляет стандартные значения (только на десктопе).
- После автозаполнения всё правится вручную.
- **Адаптив:** те же поля, свои значения.

## 4. Глобальные правила (действуют везде)

### 4.1. Удаление

- Любое удаление — сначала подтверждение.
- Если элемент ни на что не влияет: «Удалить?» → «Да / Отмена».
- Если нарушает связи: показывается **список всех активных связей** (каждая — активная ссылка для перехода к месту), варианты **«Удалить и разорвать связи»** / **«Отмена»**.
- После удаления в местах связей остаётся **активная пометка** («цвет удалён» и т.п.), находимая через фильтр «есть разорванные связи».

### 4.2. Предустановленные элементы

- Всё, что предустановлено и с чем настроена связь по умолчанию, **удалить нельзя**. Можно только **очистить значение** (тогда считается незаполненным, связь сохраняется).
- Вновь добавленные элементы удаляются по общим правилам (с предупреждением о связях).

### 4.3. Пустая связь = незаполненное поле

Если у объекта настроена ссылка, но в источнике значение не заполнено — поле считается **незаполненным**. В экспорте «только заполненные» оно **не учитывается**, хотя связь есть. Действует для всех ссылок (цвета, типографика, скругления, тени).

### 4.4. Правило сброса (внутри версии)

При изменении первичного источника (например, «Шрифт основной текст») зависимые поля обновляются **везде**, включая сброс ручных правок. Ручная правка живёт до изменения первичного.

### 4.5. Правило адаптива (между версиями)

- Цепочка: **десктоп → планшет → мобилка**.
- «Заполнить данными с десктопа» (планшет) / «Заполнить данными с планшета» (мобилка) — разовое действие, копирует всё, восстанавливает связи.
- Поле не тронуто вручную → связано с версией выше, тянется по цепочке.
- Поле изменено вручную → связь обрывается, живёт независимо.
- Повторное нажатие «Заполнить» стирает ручные правки и восстанавливает связи.
- Мобилка тянет текущее состояние планшета (включая его ручные правки — планшет для мобилки первоисточник).
- Внутри одной версии работает общее правило сброса (4.4), между версиями — правило адаптива. Это разные уровни.

### 4.6. Фильтры

- Сквозная иконка, доступна с любого экрана, сворачиваемая панель.
- Содержимое зависит от экрана: на главном — фильтры по проектам, внутри документа — по элементам.
- Отдельный фильтр-пометка «есть разорванные связи». Если связей нет — надпись «Разорванных связей нет».
- Единый набор фильтров везде, где они используются.

### 4.7. Ссылки и переходы

- Из любого поля выбора ссылки (цвет, типографика, скругление, тень) — кнопка-переход к созданию нового значения в соответствующем разделе, если нужного нет. Единообразно.

## 5. Визуальный стиль

- **Скругления везде:** кнопки, плашки, вложенные элементы. Никаких острых углов, интерфейс мягкий.
- **Образцы цвета — кружочки**, не квадратики. Пустой цвет — перечёркнутый кружок.
- **Цветовая схема:** фон и поверхности — оттенки белого/серого, без пестроты. **Один акцентный цвет** для кнопок действий и важных выделений.
- **Иконки вместо надписей** там, где интуитивно понятно (фильтры, настройки, поиск, назад и т.п.) — и на десктопе, и на мобилке. Где неочевидно — текст или иконка с подписью.
- **Мобильная вёрстка** — полноценная адаптивная, не сжатая десктопная и без горизонтальной прокрутки. Крупные элементы для пальца, удобные выпадающие списки, вертикальный экран экспорта.
- **Тема:** светлая/тёмная, по умолчанию как в системе.

## 6. Данные и хранение

- **Локальное хранение** (оффлайн-работа).
- **Синхронизация — вручную через файл** (JSON): экспорт/импорт всей базы и отдельного проекта. Никаких аккаунтов, облака, автосинхронизации, индикаторов, уведомлений.
- У каждого поля — **служебная дата последнего изменения** (невидимая), нужна для логики слияния при импорте.
- **Импорт:** выбор режима «Обновить полностью» / «Слить» (правила в п. 2.6).
- **Экспорт:** выбор версий (все/нужные), выбор объёма (заполненные/все) — каждый раз заново. Пустые в режиме «Все поля» — прочерк «—».

## 7. Что НЕ входит в проект

- Загрузка изображений/картинок — нет.
- Иконки и анимации как разделы — нет.
- Карточки и плашки как отдельный раздел — нет (только отступы и скругления/тени по ним).
- Шаблоны проектов — нет.
- Аккаунты, облачная синхронизация, автосинхронизация — нет.
- Уведомления — нет.

## 8. Рекомендуемый порядок реализации

1. **Каркас и навигация:** экраны, главный список, создание проекта, содержание, нижние панели.
2. **Раздел «Цвета»** — как эталон ссылочной логики.
3. **Раздел «Типографика»** — группы, добавление/схлопывание, параметры, ссылки.
4. **Разделы «Кнопки» и «Поля ввода»** — состояния, ссылки.
5. **«Скругления», «Тени», «Отступы и сетка».**
6. **Экспорт/импорт:** PDF, CSV, JSON, предпросмотр, слияние.
7. **Адаптив** (десктоп/планшет/мобилка) и цепочка связей.
8. **Полировка:** фильтры, разорванные связи, тема, мобильная вёрстка.
